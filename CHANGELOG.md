# История изменений

## 3.0.0 — 2026-10-12

- Python 3.12+, типизированный API, src layout и сборка по PEP 517.
- Независимые движок склонения, модели правил, загрузчик и CLI.
- Правила внутри дистрибутива вместо Git submodule; HTTPS-обновления с валидацией.
- Асинхронная загрузка и обновление правил.
- Исправлены неизменяемые формы, общие правила рода и составные имена.
- Pytest, проверки типов и стиля, GitHub Actions и GitLab CI с публикацией в PyPI.

## 2.0.1 — 2020-09-08

Предыдущий опубликованный релиз для Python 3.6+. Сохраняется в PyPI.

## 1.0.0

Удалён префикс `CASE_` у значений перечисления `Case`.
